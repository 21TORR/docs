# Tools

This is a list of all tools, that we developed and use.


## Deprecated Tools

### Firefly

Firefly is a wrapper around frontend bundler.

Just use Webpack Encore / the internal bundler in your framework (like Next.js) or Vite directly.


### php-cs

The PHP library `21torr/php-cs` is deprecated, you should use [Janus PHP] instead.


[Janus PHP]: /docs/php/tooling/janus-php
