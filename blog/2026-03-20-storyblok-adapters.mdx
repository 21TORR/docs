The Storyblok docs were updated for the adapter system, including [adapter setup and configuration][1], updated [installation docs][2], and adapter-aware [CLI][3] and [webhook][4] docs. The adapter setup example now uses `AppStoryblokAdapter` with constructor-based env autowiring and sensitive token parameters. The webhook docs now use simplified `AppStoryblokAdapter` examples for paid and unpaid plans. The adapter docs now include all provided adapter services with purpose and usage examples, with plain-text service headlines and minimal access-only code snippets.
